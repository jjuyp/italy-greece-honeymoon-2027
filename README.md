# AMORE & AEGEAN — 2027 義大利 × 希臘蜜月

2027/4/1–4/30 雙人 30 天慢旅行規劃，含海景住宿與希臘跳島。

## 網站
https://jjuyp.github.io/italy-greece-honeymoon-2027/

## 功能
- 聖托里尼夕陽主視覺、目的地風景卡片（外部 Unsplash 圖片）
- 30 天行程表與景點地理位置
- Leaflet.js + OpenStreetMap 地圖
- 希臘跳島選擇與預算試算
- Google Maps 地點導航

## 部署 GitHub Pages
1. Settings → Pages
2. Build and deployment → Source 選擇 **GitHub Actions**
3. 在 Actions 檢查 Deploy GitHub Pages 工作流程

## 技術注意
此為靜態網頁，外部圖片、Leaflet 程式庫及 OSM 圖磚需要網路。圖像為網路圖片，不是原設計稿或真實酒店照片，請於正式使用前確認授權與替換。交通、預算及 2027 年渡輪時間尚未完成即時訂位核實。
